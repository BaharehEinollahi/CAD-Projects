# CAD Projects README

This repository contains Verilog hardware designs, data paths, and controllers for the Computer-Aided Design course projects.

## Projects Overview

* **1-Pseudo-Random Number Generator:** Implements a hardware circuit with shift registers, a counter, and a barrel shifter to generate pseudo-random numbers.


* **2-Vector Operations & Dot Product:** Implements vector arithmetic and dot product calculations using input arrays, custom multiplexers, and valid signal handlers.


* **3,4-Optimized Hash Circuit & ACTEL Mapping:** Focuses on gate-count optimization using custom base library cells (`c1`, `c2`, `s1`, `s2`) and mapping LUTs to ACTEL cells.


* **Midterm Project:** Implements an 8-bit input processing unit featuring a priority encoder, a barrel shifter, and an accumulator with an adder.
